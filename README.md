# QSDC_DL04_PingPong
A simulation-based implementation and analysis of Quantum Secure Direct Communication (QSDC) protocols, including DL04 and Ping-Pong schemes. The project evaluates communication security and performance under ideal and non-ideal quantum channels with depolarizing noise and intercept-resend attacks. This project focuses simulink hardware based implementation of secuirity check of DL04 protocol under ideal noiseless channel. Also it includes the matlab simulation various parameters of ping pong protocol under varying eavesdropping and noise levels .

Key Features
DL04 QSDC Protocol
Ping-Pong QSDC Protocol
MATLAB/Simulink Implementation
Polarization-Based Qubit Modeling
Intercept-Resend Attack Simulation
QBER Analysis
Fidelity Analysis
SBER Calculation
Latency Evaluation
Security and Performance Comparison
